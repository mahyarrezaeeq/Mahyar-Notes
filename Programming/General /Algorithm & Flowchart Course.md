الگوریتم یعنی یک مسئله را قدم به قدم حل کنیم و فلوچارت یعنی برای فهم بهتر آن را با نماد هایی نمایش دهیم.

Algorithm ==> Solve sth step by step.

مثال : الگوریتم جمع دو عدد را بنویسید.
1-Start
2-Input ==> i
3-Input ==> j 
4-Sum ==> i + j 
5-print(sum)
6-End , Stop 
 نماد های فلوچارت عبارتند از: 
 1-نماد دایره که برای Start و Stop یعنی شروع و پایان استفاده می شود.
 2-نماد متوازی الاضلاع که برای گرفتن ورودی یا Input استفاده می شود.
 3-نماد مستطیل که برای عمل هایی مانند جمع و تفریق و ضرب و تقسیم و ... استفاده می شود.
 4-نماد دایره-فلش که برای نشان دادن خروجی یا Output استفاده می شود.

مثال: معدل فردی را بررسی کرده و Pass یا Fail شدن او را مشخص کنید.
Algorithm:
1-Start
2-Input ==> q1 , q2 , q3 , q4 
3-Grade ==> (q1 + q2 + q3 + q4 ) / 4 
4-If(Grade < 50)then 
		print(Fail)
	else 
		print(Pass)
5-Stop


در تمامی زبان های برنامه نویسی و دنیای کامپیوتر مفاهیمی داریم که تقریبا یکسان هستند و فهم آن ها برای هر برنامه نویسی لازم است. در ادامه با آن ها آشنا می شویم.

==اپراتور شرطی :== در تمامی زبان های برنامه نویسی وجود دارد و از موارد زیر تشکیل شده است : 
1-عملگر == : که برای سنجش مساوی بودن دو چیز استفاده می شود. 
2-عملگر < : بزرگتر که همانند آن را در ریاضیات نیز داریم.
3-عملگر > : کوچکتر که همانند آن را در ریاضیات نیز داریم.
4-عملگر =< : بزرگتر مساوی که همانند آن را در ریاضیات نیز داریم.
5-عملگر => : کوچکتر مساوی که همانند آن را در ریاضیات نیز داریم.
6-عملگر =! : نقیض که برای زمانی به کار می رود که می خواهیم نشان دهیم دو چیز برابر نیستند.

==متغیر :== مانند ظرفی است که مقادیر را در آن می ریزیم تا از آن در جاهای مختلف برنامه خود استفاده کنیم. 
متغیر ها در دنیای برنامه نویسی انواع مختلفی داریم که با آن ها آشنا خواهیم شد :
1-عدد صحیح (int)
2-عدد اعشاری (float) 
3-بولین (boolean)
4-حروف و کاراکتر (char , string)
5-عدد مختلط (complex)

==عملگرها :== عملگر های ریاضی در تمامی زبان های برنامه نویسی وجود دارند که عبارتند از : 
1-عملگر % : باقی مانده تقسیم 
2-عملگر /  : تقسیم 
3-عملگر * : ضرب
4-عملگر ** : توان
5-عملگر - : منها 
6-عملگر + : جمع 
7-عملگر -- : یکی کم می کند.
8-عملگر ++ : یکی اضافه می کند.

عملگر هایی مانند OR و AND نیز داریم که به صورت زیر هستند :
1-عملگر OR : زمانی True است که حداقل یکی از ورودی های آن True باشد.
2-عملگر AND : زمانی True است که هر دو ورودی آن True باشند.

==شرط ها و حلقه ها :== در تمامی زبان ها وجود دارند فقط Syntax متفاوتی داریم که برای مثال در ++C با بلوک بندی همراه با } و { مشخص می شود و در Python بلوک بندی با Indent ها یا همان تو رفتگی ها صورت می گیرد.
1-شرط if :

```python
if condition :
	print()
elif condtion :
	print()
else:
	print()
```

2-شرط if در یک خط : 

```C++
if (condition)?"yes": "No";
```


3-حلقه while :

```python
while condition : 
	print()
```

4-حلقه for : 

```python
for variable in sth : 
	print()
```

5-موقعیت های Switch :

```C++
int age = 12; 
switch (age)
case 10; 
break; 
case 12; 
break; 
```

==انواع روش های برنامه نویسی :== 
1-برنامه نویسی روالی (Procedual Programming) : خط به خط خوانده و اجرا می شود که به این روش برنامه نویسی روالی می گوییم یعنی تحت یک روال خاص خوانده و اجرا می شوند.
2-برنامه نویسی تابعی (Functional Programming) : برنامه نویسی با استفاده از توابع که هر تابع بخشی مربوط به خود را دارد و کار مربوط به خود را انجام می دهد.
3-برنامه نویسی شی گرا (OOP(Object Oriented Programming)) : مدرن ترین و بهترین نوع برنامه نویسی  برنامه نویسی شی گرا می باشد.
تفکر Class و محصول Object است.
اعضای درون Class را Field و خصوصیات هر Field را Property می گوییم.
کاری که با Method های یک Class انجام می شود Event نام دارد.
